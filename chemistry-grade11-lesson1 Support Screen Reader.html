🎯 គោលបំណងមេរៀន
  • ពណ៌នានិមិត្តសញ្ញាគីមីនៃធាតុមួយចំនួន
  • កំណត់និយមន័យវ៉ាឡង់ វ៉ាឌីកាល់ ម៉ាសអាតូមធៀប និងម៉ាសម៉ូលេគុលធៀប
  • គណនាម៉ាសម៉ូលេគុលធៀប និងភាគរយម៉ាសនៃធាតុក្នុងសមាសធាតុ
  • កំណត់រូបមន្តដំបូង និងសរសេរសមីការគីមី សមីការអ៊ីយ៉ុង

១. និមិត្តសញ្ញា និងរូបមន្តគីមី

១.១ និមិត្តសញ្ញានៃធាតុគីមី

ធាតុគីមីនីមួយៗមាននិមិត្តសញ្ញាផ្ទាល់ខ្លួន ដែលជាទូទៅយក អក្សរទីមួយ (អក្សរធំ) នៃឈ្មោះឡាតាំង ឬសរសេរជាមួយអក្សរតូចទី២ ឬទី៣ នៃឈ្មោះនោះ។ ធាតុខ្លះប្រើឈ្មោះឡាតាំង។

អក្សរទីមួយអក្សរទី២អក្សរទី១ និងទី៣ពាក្យឡាតាំង

១.២ រូបមន្តគីមី

សមាសធាតុគីមីតាងដោយ រូបមន្តគីមី ដែលបង្ហាញពីចំនួនអាតូម ឬអ៊ីយ៉ុងដែលចូលផ្សំ។ ក្នុងសមាសធាតុអ៊ីយ៉ុង ផលបូកបន្ទុកវិជ្ជមាន = ផលបូកបន្ទុកអវិជ្ជមាន (សរុបស្មើ ០)។ ឧទាហរណ៍ Na+ និង Cl- → NaCl។ Na+ ពីរ និង CO32- មួយ → Na2CO3។ Al3+ មួយ ត្រូវការ NO3- បី → Al(NO3)3។

២. វ៉ាឡង់ និងរូបមន្តគីមី

២.១ វ៉ាឡង់

វ៉ាឡង់ គឺជាលទ្ធភាពចូលផ្សំរវាងអាតូម ឬវ៉ាឌីកាល់ជាមួយធាតុដទៃទៀត ហើយជាចំនួនគត់តូច ឬសូន្យ។ ធាតុដែលមានវ៉ាឡង់សូន្យ (ពពួកឧស្ម័នកម្រ) មិនបង្កើតជាសមាសធាតុទេ។ ធាតុខ្លះមានវ៉ាឡង់ច្រើនជាងមួយ ឧ. ទង់ដែង(I) ខុសពី ទង់ដែង(II); ដែក(II) ខុសពី ដែក(III)។

២.២ វ៉ាឌីកាល់

វ៉ាឌីកាល់ គឺជាក្រុមអាតូមដែលចូលរួមក្នុងរូបមន្តម៉ូលេគុលនៃសមាសធាតុមួយចំនួន ឧ. អ៊ីដ្រុកស៊ីត (OH) ក្នុង NaOH និង Al(OH)3។

២.៣ ការសរសេររូបមន្តគីមី

ធាតុ/វ៉ាឌីកាល់វ៉ាឡង់ធាតុ/វ៉ាឌីកាល់វ៉ាឡង់
He, Ne០OH (អ៊ីដ្រុកស៊ីត)១
H, Li, Na១NO3 (នីត្រាត)១
Mg, Zn២NH4 (អាម៉ូញ៉ូម)១
Fe២ ឬ ៣HCO3 (ប៊ីកាបូណាត)១
S២, ៤, ៦CO3 / SO4២
——PO4 (ផូស្វាត)៣
វិធីសរសេរ (ច្បាប់គុណខ្វែង)
  • ធាតុ A វ៉ាឡង់ x និងធាតុ B វ៉ាឡង់ y → រូបមន្ត AyBx។ បើ x = y ត្រូវសម្រួល → AB។
  • ឧ. Al(+3) និង O(−២) → Al2O3។ ផ្ទៀងផ្ទាត់៖ 2(+3) + 3(−2) = 0 ✔
  • ឧ. C(+4) និង O(−២) → C2O4 → សម្រួល CO2។
  • ឌីអេឡិចត្រុង៖ H វ៉ាឡង់ ១ · O វ៉ាឡង់ ២ · N វ៉ាឡង់ ៣ · C វ៉ាឡង់ ៤។

៣. ម៉ាស់ធៀប

៣.១ ម៉ាសអាតូមធៀប (Ar)

ម៉ាសអាតូមធៀប គឺជាផលធៀបរវាងម៉ាសអាតូមនៃធាតុ និង 1/12 នៃម៉ាសអាតូម កាបូន-12 (12C)។ វាគ្មានខ្នាត។ ឧ. Ar(H)=1, Ar(O)=16, Ar(Fe)=56។

Ar = ម៉ាសអាតូមនៃធាតុ ÷ ( 1/12 × ម៉ាសអាតូម C-12 )
ធាតុArធាតុArធាតុAr
H1Ca40Cl35.5
He4Fe56Pb207
C12Cu64Ag108
N14Zn65I127
O16Mg24Na23

៣.២ ម៉ាសម៉ូលេគុលធៀប (Mr)

ម៉ាសម៉ូលេគុលធៀប គឺជាផលបូកម៉ាសអាតូមធៀបនៃអាតូមទាំងអស់ក្នុងម៉ូលេគុល។

Mr = ម៉ាសម៉ូលេគុល ÷ ( 1/12 × ម៉ាសអាតូម C-12 ) = ΣAr

ឧ. ១ Mr(O2) = 2 × 16 = 32។ ឧ. ២ Mr(H2SO4) = (2×1) + 32 + (4×16) = 98។

៤. សមាសភាគភាគរយ

៤.១ ភាគរយម៉ាសនៃធាតុ

ភាគរយម៉ាសនៃធាតុ = (n × Ar ÷ Mr) × 100%។ ឧ. NaCl៖ Mr=58.5 → %Na = 23/58.5×100 = 39.32% ; %Cl = 35.5/58.5×100 = 60.68% (ផលបូក 100%)។

៤.២ ម៉ាសធាតុក្នុងម៉ាសសមាសធាតុ

ម៉ាសធាតុ = ( n × Ar ÷ Mr ) × ម៉ាសសមាសធាតុ

ឧ. ក្នុង CuSO4 32 g៖ Mr=64+32+64=160 → ម៉ាស Cu = 64/160 × 32 = 12.8 g។

៥. ទឹកគ្រីស្តាល់ (ទឹកក្នុងគ្រីស្តាល់)

ម៉ាសទឹក = ( n × Mr(H2O) ÷ Mr(គ្រីស្តាល់) ) × ម៉ាសគ្រីស្តាល់

ឧ. ក្នុង Na2CO3·10H2O 10 g៖ Mr=286 ; ទឹក 10×18=180 → ម៉ាសទឹក = 180/286 × 10 = 6.29 g។

៦. រូបមន្តដំបូង

រូបមន្តដំបូង បង្ហាញសមាមាត្រចំនួនអាតូមសាមញ្ញបំផុតនៃធាតុក្នុងសមាសធាតុ។ ជំហាន៖ (១) យក % ឬម៉ាសនៃធាតុនីមួយៗ (២) ចែកនឹង Ar (៣) ចែកនឹងចំនួនតូចបំផុត (៤) បំប្លែងជាចំនួនគត់ ទើបសរសេររូបមន្ត។

ឧ. 88.89% O និង 11.11% H៖ H = 11.11/1 = 11.11 ; O = 88.89/16 = 5.55 → ចែកនឹង 5.55 បាន H : O = 2 : 1 → រូបមន្តដំបូង H2O។

៧. សមីការគីមី

សមីការគីមី គឺការសរសេរតាងប្រតិកម្មគីមី៖ សារធាតុកំណើត (សារធាតុចូល) → សារធាតុកកើត (សារធាតុចេញ)។ សមីការត្រូវតុល្យ គឺចំនួនអាតូមនៃធាតុនីមួយៗសងខាងស្មើគ្នា ដោយប្រើមេគុណ។ សញ្ញាសភាព៖ (s) រឹង · (l) រាវ · (g) ឧស្ម័ន · (aq) ដំណោះស្រាយទឹក។

សមីការពាក្យ៖ ម៉ាញេស្យូម + អុកស៊ីសែន → ម៉ាញេស្យូមអុកស៊ីត
សមីការគីមី៖ 2Mg(s) + O2(g) → 2MgO(s)

៨. សមីការអ៊ីយ៉ុង

សមីការអ៊ីយ៉ុង បង្ហាញតែអ៊ីយ៉ុងដែលចូលរួមក្នុងប្រតិកម្មពិតប្រាកដ។ អ៊ីយ៉ុងដែលមិនចូលរួម (អ៊ីយ៉ុងអ្នកមើល) ត្រូវលុបចោល។ ឧទាហរណ៍៖

2NaOH(aq) + CuSO4(aq) → Cu(OH)2(s) + Na2SO4(aq)
2Na+ + 2OH- + Cu2+ + SO42- → Cu(OH)2(s) + 2Na+ + SO42-

Na+ និង SO42- ជាអ៊ីយ៉ុងអ្នកមើល (មានសងខាង) → សមីការអ៊ីយ៉ុងសុទ្ធ៖

Cu2+(aq) + 2OH-(aq) → Cu(OH)2(s)
📌 ចំណុចសំខាន់ត្រូវចងចាំ
  • និមិត្តសញ្ញាគីមី៖ អក្សរទីមួយ (ធំ) + អក្សរតូច ឬពាក្យឡាតាំង។
  • រូបមន្តគីមី៖ ផលបូកបន្ទុក (+) = ផលបូកបន្ទុក (−) ; ប្រើច្បាប់គុណខ្វែងនៃវ៉ាឡង់។
  • Ar គ្មានខ្នាត ; Mr = ΣAr។
  • %ធាតុ = (n×Ar/Mr)×100% ។
  • រូបមន្តដំបូង៖ % → ÷Ar → ÷ចំនួនតូចបំផុត។
  • សមីការត្រូវតុល្យ ; សមីការអ៊ីយ៉ុងលុបអ៊ីយ៉ុងអ្នកមើល។

✅ លំហាត់ទី១ · និយមន័យ
ម៉ាសអាតូមធៀប (Ar) ៖ ផលធៀបរវាងម៉ាសអាតូមនៃធាតុ និង 1/12 នៃម៉ាសអាតូមកាបូន-12។
ម៉ាសម៉ូលេគុលធៀប (Mr) ៖ ផលធៀបរវាងម៉ាសម៉ូលេគុល និង 1/12 នៃម៉ាសអាតូមកាបូន-12 ឬស្មើផលបូក Ar នៃអាតូមក្នុងម៉ូលេគុល។
✅ លំហាត់ទី២ · គណនា Mr
Mr(ZnO) = 65 + 16 = 81
Mr(CO2) = 12 + 2×16 = 44
Mr(CH4) = 12 + 4×1 = 16
Mr((NH4)2SO4) = 2×(14+4) + 32 + 4×16 = 132
Mr(O2) = 2×16 = 32
Mr(Cl2) = 2×35.5 = 71
✅ លំហាត់ទី៣ · សរសេររូបមន្តគីមី
ក. ម៉ាញេស្យូមស៊ុលផាត៖ Mg2+, SO42- → MgSO4
ខ. ស័ង្កសីអុកស៊ីត៖ Zn2+, O2- → ZnO
គ. សំណ(II) ក្លរួ៖ Pb2+, Cl- → PbCl2
ឃ. ដែក(III) ស៊ុលផាត៖ Fe3+, SO42- → Fe2(SO4)3
✅ លំហាត់ទី៤ · តុល្យសមីការ
ក. 2Cu(s) + O2(g) → 2CuO(s)
ខ. Mg(s) + 2HCl(aq) → MgCl2(aq) + H2(g)
គ. Fe2O3(s) + 2Al(s) → Al2O3(s) + 2Fe(s)
ឃ. 2Na(s) + 2H2O(l) → 2NaOH(aq) + H2(g)
✅ លំហាត់ទី៥ · សរសេរសមីការ
ក. Fe + H2SO4 → FeSO4 + H2
ខ. C + O2 → CO2
គ. 2Fe2O3 + 3C → 4Fe + 3CO2
✅ លំហាត់ទី៦ · ម៉ាសទឹកគ្រីស្តាល់
ក. MgSO4·7H2O៖ Mr = 24+32+64+7×18 = 246 ; ម៉ាសទឹក = 126/246 × 12.3 = 6.3 g
ខ. FeCl3·6H2O៖ Mr = 56+106.5+108 = 270.5 ; ម៉ាសទឹក = 108/270.5 × 54.1 = 21.6 g
✅ លំហាត់ទី៧ · ភាគរយម៉ាស
ក. Cu ក្នុង CuO៖ Mr=80 → 64/80×100 = 80%
ខ. Mg ក្នុង MgSO4៖ Mr=120 → 24/120×100 = 20%
គ. Na ក្នុង NaOH៖ Mr=40 → 23/40×100 = 57.5%
✅ លំហាត់ទី៨ · ម៉ាសធាតុ
ក. Ca ក្នុង CaCO3 25 g៖ Mr=100 → 40/100×25 = 10 g
ខ. Cu ក្នុង CuCl2 27 g៖ Mr=64+71=135 → 64/135×27 = 12.8 g
✅ លំហាត់ទី៩ · រូបមន្តដំបូង
ក. 75% C, 25% H៖ C = 75/12 = 6.25 ; H = 25/1 = 25 → ÷6.25 បាន C : H = 1 : 4 → CH4
ខ. 80% C, 20% H៖ C = 80/12 = 6.67 ; H = 20 → ÷6.67 បាន C : H = 1 : 3 → រូបមន្តដំបូង CH3 (បើ Mr=30 រូបមន្តម៉ូលេគុលគឺ C2H6)
